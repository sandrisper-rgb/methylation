# Methylation & Colitis

Collaborative Quarto research website led by Sandra Perdomo at Universidad El Bosque. It organizes project findings, research literature, student presentations, and reproducible R workflows.

## Run locally

```bash
quarto preview
```

To render the complete site:

```bash
quarto render
```

See [contributing.qmd](contributing.qmd) for the student workflow and public-data safeguards.

## Before publishing

1. Confirm Sandra's preferred name, title, department, biography, and contact details.
2. Add the approved study question, protocol, ethics information, and repository license.
3. In the GitHub repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.
